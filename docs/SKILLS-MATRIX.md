## Status Convention
- **Implemented** — runnable code exists in the repository.
- **Architecture** — design and implementation plan exists; code may still be in progress.
- **Planned** — reserved for future implementation.

No performance metric should be treated as demonstrated unless a reproducible experiment and its output are committed.
