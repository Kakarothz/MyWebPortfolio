# Portfolio Roadmap

The goal is to turn the IBM AI Engineering learning path into a concise set of independent, reproducible engineering demonstrations.

## Phase 1 — Foundations
- Machine-learning pipeline
- TensorFlow/Keras neural network
- PyTorch neural network

## Phase 2 — Language Models
- Transformer NLP inference
- LLM fine-tuning lab

## Phase 3 — Applied GenAI
- RAG knowledge assistant
- Agentic AI workflow

## Quality Bar
Each implementation should include a clear problem statement, setup instructions, reproducible entry point, dependency list, evaluation approach, limitations and next steps.

## Integrity
Projects are portfolio implementations inspired by learned competencies. Course completion and portfolio implementation are intentionally kept separate so the repository does not imply unsupported project history or fabricated results.
