## Portfolio Projects
This repository is organized as a growing set of **independent portfolio implementations** inspired by technical areas covered in the IBM AI Engineering program. They demonstrate applied engineering rather than reproduce Coursera assessment submissions.

- **01 — Machine Learning Pipeline:** preprocessing, training, evaluation and reusable inference.
- **02 — TensorFlow / Keras Deep Learning:** model construction, training, validation and inference.
- **03 — PyTorch Neural Network:** datasets, model definition, optimization and evaluation.
- **04 — Transformer NLP:** tokenization, pretrained transformer models and inference.
- **05 — LLM Fine-Tuning Lab:** architecture for model adaptation and evaluation.
- **06 — RAG Knowledge Assistant:** ingestion, chunking, embeddings, retrieval and grounded generation.
- **07 — Agentic AI Workflow:** agent architecture, retrieval/tool boundaries and auditable execution.

> **Status:** Implementations are developed incrementally. Each project clearly distinguishes implemented code from architecture notes or planned work.
